How to use

  1. Start Autopilot. Go to the Autopilot tab, set the strategy inputs, and press Start Autopilot.
  2. Monitor. Quick metrics show Capital used, Target capacity, Net deployed, and green/red P/L. The Autopilot tab shows the active ladder.
  3. Stop. Use Stop Autopilot anytime. Use Panic close to cancel all orders and flatten.
